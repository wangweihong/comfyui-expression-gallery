# ComfyUI Expression Gallery · 表情图库

本地白模表情参考图库，支持中文 / English。图库浏览参考 costume-gallery，标签搜索、多选、已选标签、关联计数与管理窗口参考提示词库节点。

## 浏览与标注

- **13 个大类**：基础情绪，以及害羞与社交不自在、低落与受挫、轻蔑与优越感、疑惑与思考、紧张与不安、烦躁与抗拒、愉悦的细分、调皮与暧昧互动、哭泣与笑容形态、身体感受与状态、成人亲密情境、混合表情。数量为 0 的类目也会显示。
- **83 个表情类型**、**32 个面部动作**、**6 档强度**：未标注、微弱、轻度、中度、强烈、夸张。
- 多选表情类型与面部动作；每张图的强度为单选。多个筛选标签需全部匹配。
- 大图点击“编辑标签”进行单张标注；“批量标注”可勾选图片、选择已显示或全部筛选结果，按维度追加、替换或移除标签。
- 分类 / 标签管理支持中英文名称、搜索别名、新增、改名、调整表情类型所属大类、关联数量、移除与恢复。

初始七类为普通、可编辑的标签，也可以移除或替换。面部动作和强度初始为未标注；此版本不自动推断细分表情。成人类目是预留的创作情境标签。

移除类目或标签会隐藏对应项，关联记录与图片保留，可通过“显示已移除”恢复。强度的“未标注”是系统保留项。并发编辑发生冲突时，点击重新加载后再保存。

## 节点

将本目录放到当前 ComfyUI 的 `custom_nodes`，重启 ComfyUI 并刷新页面。搜索 **Expression Gallery 白模表情图库**，类型为 `ExpressionClayGallery`。节点直接显示所选图片，点击预览图或浏览按钮打开对应表情详情；选择其他表情后，编号和预览同步更新。

旧版原照片选择节点 `ExpressionGallery` 已移除。历史工作流使用现有图片读取节点保留原照片、中性参考图及标签连线，白模与自定义表情统一使用 `ExpressionClayGallery`。

图库入口：<http://127.0.0.1:8188/expression_gallery/gallery>

ComfyUI 顶部工具栏也提供“表情图库 / Expressions”入口，点击后弹出图库，沿用上次选择的界面语言，可直接浏览、上传和管理素材。选入工作流时，从表情图库节点打开并选择图片。

输出仅保留三个常用端口：

1. 图像
2. 英文表情
3. 中文表情

内置素材输出当前可编辑的表情类型名称；自定义素材输出中英文名称。宽高可通过通用图像尺寸节点读取，编号在节点输入中查看，面部动作与强度等标签在图库中管理。

加载旧工作流时自动精简端口，并保留图像、英文和中文表情的连线。已连接的其他旧输出会提示先调整连线，避免误接或丢失。选择图片不会自动运行工作流。

## 自定义与删除素材

- 点击“上传自定义表情”，选择静态 PNG、JPEG 或 WebP；单张不超过 20 MiB、3200 万像素。中英文名称至少填一种，支持表情类型、面部动作与强度标签。
- 上传保留原尺寸和透明通道，保存为 PNG；缩略图与节点 IMAGE 输出使用白色背景。上传只保存参考图，不执行白模转换或排队生图。
- 来源筛选支持内置 / 自定义。自定义素材可以改名、编辑标签、选入节点和删除。自定义的中英文名称通过节点 expression_en / expression_zh 输出；面部动作与强度在图库中管理。
- 大图“删除表情”和批量“删除已选素材”支持内置与自定义素材。“管理内置素材”提供搜索、多选、删除、仅保留缩略图、保留 / 重新启用。
- 删除前显示素材、文件数量和预计释放空间，再确认执行。删除会实际移除生成图及缩略图，无法撤销；输入照片和标签词表保留。仅保留缩略图的素材不能选入节点执行。
- 删除状态持久保存，重新出现的文件不会自行恢复显示。重新启用前需先补回原图和缩略图；此操作不自动重新生成图片。

## 数据与备份

默认读取当前 ComfyUI 输出目录的 `images/表情/白模/`。可设置 `COMFYUI_EXPRESSION_LIBRARY` 指向完整图库目录。

- PNG：生成的 512×512 白模图像，目前共 490 张。
- `.gallery/catalog.json`：素材索引。
- `.gallery/thumbs/`：预览缩略图。
- `.gallery/custom/`：用户上传的 PNG，以独立 `u-` 编号保存。
- `.gallery/annotations.sqlite3`：分类、标签词表、别名、素材标注、自定义元数据和删除状态。

备份或迁移时，请保留整个白模目录，包括隐藏的 `.gallery`。标签编辑持久化到数据库，节点与图库读取当前标注。词表初始配置位于插件的 `data/taxonomy.json`。

示例工作流位于 `example_workflows/`：白模表情预览、Qwen21 单张表情转白模。转换沿用用户原工作流的 Qwen Image 2.1 Turbo BF16、Euler 八步、CFG 1、种子 20261014 ，输入缩放到 512×512，并开启材质优化 VAE。
